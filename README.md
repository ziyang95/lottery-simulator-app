# 彩票模拟器（iPhone 网页/PWA）

## 功能
- 依据用户提供的 Java 字节码可辨认的规则随机生成号码：红球 1–35 选 5 个，蓝球 1–12 选 2 个。
- 支持生成一注或连续生成五注，保留最多 200 条本机历史记录。
- Service Worker 缓存与访问时更新检查；新版本安装后自动接管并刷新。
- 尽量禁止 iOS 网页长按菜单、文字选择、复制/剪切/粘贴；禁止页面缩放。

## 发布到 GitHub Pages
把全部文件上传到仓库并提交，开启 Settings → Pages。部署后使用 GitHub Pages 地址访问。修改后需先成功部署，联网打开时才会检查更新。

## 注意
此程序是随机模拟器，不预测中奖、不连接真实销售/投注服务。网页无法保证拦截所有 iOS 系统级长按菜单。号码规则依据上传的 test.class 字节码中可辨认的随机算法；原始中文提示字符串在字节码中显示为乱码，无法确认具体彩票品种。
